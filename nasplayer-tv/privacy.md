# 개인정보 처리방침

**적용 대상**: NAS Player (tvOS · App Store 이름 Easy NAS Player TV)
**최종 수정일**: 2026-10-27 **버전**: 1.0

---

## 1. 요약

개발자는 사용자 데이터를 수집하지 않습니다.

개발자가 운영하는 서버가 없으며, 앱에서 개발자에게 데이터를 전송하는 네트워크 경로도 없습니다. 데이터는 Apple TV 와 사용자가 직접 설정한 서버(NAS · 파일 서버) 사이에서만 오가며, 개발자는 이를 열람할 수 없습니다.

이 앱은 **무료이며 광고와 인앱 구입이 없습니다.** 광고 SDK, 분석 SDK, 오류 보고 SDK 를 포함하지 않으며, 사용자를 추적하지 않습니다.
또한 **업로드 · 다운로드 기능이 없습니다.** 서버의 사진과 동영상을 읽어 화면에 보여 주고 재생할 뿐, 파일을 Apple TV 에 내려받아 보관하거나 Apple TV 의 데이터를 서버로 올리지 않습니다.

## 2. 원칙

- **추적하지 않습니다.** 앱 추적 투명성(ATT) 권한을 요청하지 않고, 광고 식별자(IDFA)나 기기 식별자를 읽지 않습니다.
- **광고 · 분석 · 오류 보고 SDK 를 쓰지 않습니다.** 포함된 서드파티 라이브러리는 동영상 재생과 서버 연결을 위한 오픈소스뿐이며(§8), 데이터 수집 · 분석 · 광고 기능이 없습니다.
- **개발자에게 전송되는 데이터는 없습니다.** 사용 기록, 기기 정보, 오류 보고를 포함해 어떠한 데이터도 개발자에게 전송되지 않습니다.
- **사용자 데이터를 판매하거나 제3자와 공유하지 않습니다.** 개발자가 보유하는 사용자 데이터 자체가 없습니다.

## 3. 앱이 기기에 저장하는 것

### 3.1 Keychain — 서버 프로필과 신뢰 정보

NAS 주소와 계정 같은 민감한 정보는 tvOS Keychain 에 이 앱 전용(서비스 `com.nasplayer.tv.keychain`, 접근 그룹 `$(AppIdentifierPrefix)com.nasplayer.tv`)으로 저장되며, 다른 앱과 공유되지 않습니다.

1. **서버 프로필** (`nas.profiles.v2`)
   - 공통: 서버 종류, 프로필 이름, 주소, 포트, 계정 이름, 비밀번호, 폴더 설정(탐색 시작 폴더 · 최근 폴더 목록), 프로필 식별자(UUID).
   - Synology NAS: QuickConnect ID 사용 여부, HTTPS 사용 여부, 2단계 인증 시드(TOTP, 사용자가 넣은 경우), DSM 이 발급한 기기 신뢰 토큰과 만료 시각.
   - SMB 서버: 공유 이름, 도메인.
   - SFTP 서버: 시작 경로, 인증 방식(비밀번호 또는 개인 키), 사용자가 넣은 OpenSSH 개인 키와 암호 문구, 최초 연결 때 사용자가 신뢰한 서버 호스트 키 지문.
2. **NAS 인증서 신뢰 지문** (`certtrust.nas.v1`): 사용자가 직접 승인한 자체 서명 인증서의 지문. 다음 접속 때 대조용으로만 씁니다.

보호 방식은 `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly` 입니다. 이 항목들은 iCloud Keychain 으로 동기화되지 않고 기기 백업에도 포함되지 않아 **이 Apple TV 를 벗어나지 않습니다.**

### 3.2 앱 환경설정 (UserDefaults)

화면 모드, 정렬 방식, 보기 방식, 그리드 열 수, 재생 엔진, 자막 스타일, 동영상 이어보기 지점, 마지막으로 탐색한 위치 같은 값은 기기의 표준 저장소(UserDefaults)에 보관되며 이 앱만 접근할 수 있습니다.

### 3.3 이미지와 임시 파일

- 썸네일과 사진 이미지는 화면에 보여 주기 위해 **메모리에만** 잠시 보관하며, 앱을 종료하면 사라집니다.
- SFTP 서버의 동영상을 재생할 때 같은 이름의 자막 파일이 있으면, 재생에 붙이기 위해 기기의 임시 폴더로 읽어 옵니다. 이는 재생을 위한 일시적 처리이며 사용자가 쓰는 다운로드 기능이 아닙니다.
- 사진 · 동영상 원본을 Apple TV 에 보관하지 않습니다.

## 4. iCloud 로 나가는 것 — 설정값뿐입니다

앱은 Apple 의 iCloud Key-Value 저장소(이 앱 전용 식별자 `$(TeamIdentifierPrefix)com.nasplayer.tv`)를 이용해 일부 설정값을 같은 Apple 계정의 다른 Apple TV 와 동기화합니다.

- 동기화 항목: 화면 모드, 그리드 열 수, NAS 목록 정렬 기준과 방향, 폴더 보기 방식, 활성 프로필 식별자(UUID), 앞/뒤 이동 시간, 기본 재생 엔진, 재생 방식 선택 창 표시 여부, 다음 영상 자동 재생 여부, 업스케일링 · 선명화 여부, 슬라이드쇼 간격. iPhone 판과 같은 설정 형식을 쓰기 때문에 업로드 관련 설정값 두 개(기본 업로드 폴더 경로, 파일 이름 중복 시 자동 번호)도 목록에 있지만, 이 앱에는 업로드 기능이 없습니다.
- 동기화 제외: 비밀번호를 포함한 모든 자격 증명, 사진 · 동영상 원본, 동영상 이어보기 지점, 마지막 위치, 최근 폴더 목록, 진단 로그.
- 데이터는 사용자의 iCloud 계정에 보관되며 개발자는 접근할 수 없습니다. 앱에 동기화를 켜고 끄는 설정은 없습니다. iCloud 에서 로그아웃하면 동기화되지 않습니다.

## 5. 진단 로그

앱은 문제 원인을 찾기 위해 기기 안에 진단 로그를 기록합니다.

- 화면에서 볼 수 있는 최근 기록(메모리, 최대 500건)과, 기기 안 앱 컨테이너의 세션 기록 파일(최근 10개만 유지)입니다.
- **외부로 전송되지 않습니다.** tvOS 판에는 로그를 내보내는 기능도 없습니다.
- 기록 내용: 작업 시각과 결과, 오류 메시지, 접속한 서버 주소와 요청 경로. 비밀번호와 2단계 인증 시드는 기록하지 않으며, 서버 세션 키는 마스킹합니다.

## 6. 앱이 통신하는 상대

앱은 **사용자가 서버 설정 화면에 직접 입력한 서버**와만 통신합니다: Synology NAS, SMB 파일 서버(Windows · macOS · NAS 공유 폴더), SFTP 서버.

- 주소(내부 IP, 공인 도메인 · IP, 또는 Synology QuickConnect ID)와 포트, HTTPS 사용 여부는 모두 사용자가 정합니다.
- QuickConnect ID 를 쓰는 경우에 한해, 그 ID 를 실제 접속 주소로 바꾸기 위해 Synology 가 운영하는 QuickConnect 조회 서버(`global.quickconnect.to`)에 질의합니다.
- 주변 기기를 자동으로 탐색하거나 스캔하지 않습니다(Bonjour/mDNS 브라우징 · 서브넷 스캔 없음).
- 앱 안에 웹 브라우저가 없어 임의의 웹사이트에 접속하지 않습니다.
- **업로드와 다운로드가 없습니다.** 서버와 주고받는 것은 폴더 목록, 사진 · 동영상 · 자막 읽기(표시 · 재생용), 그리고 사용자가 직접 실행한 서버 쪽 파일 관리(새 폴더 · 이름 변경 · 삭제 · 이동 · 압축 · 압축 풀기)뿐입니다.
- SFTP 서버에 처음 연결할 때 호스트 키 지문을 보여 주고, 사용자가 신뢰해야 연결합니다. 이후 키가 바뀌면 연결을 막습니다.
- 개발자가 운영하는 서버는 없으며, 개발자에게 어떠한 네트워크 요청도 보내지 않습니다. Apple 의 시스템 서비스(iCloud Key-Value 저장소, App Store)는 tvOS 가 처리합니다.

## 7. 보안

- **암호화 연결 우선**: 서버가 HTTPS 를 지원하고 사용자가 HTTPS 를 켠 경우 HTTPS(TLS)로 연결합니다. SFTP 는 SSH 로 인증과 파일 데이터 전송이 모두 암호화됩니다.
- **평문 전송을 쓰는 경우**: 앱은 `NSAllowsArbitraryLoads = true` 로 설정되어 있으며, 다음 세 경우 암호화되지 않은 전송이 쓰입니다. 상대는 언제나 사용자가 주소를 입력한 개인 서버입니다.
  1. NAS 에서 HTTPS 를 쓰지 않을 때 — Synology DSM 의 기본값은 HTTP(포트 5000)입니다.
  2. Synology 동영상 재생 — 재생 엔진은 앱이 저장한 자체 서명 인증서 신뢰를 공유하지 못해 NAS 의 HTTP 포트로 연결합니다.
  3. SMB 서버 — SMB 3 의 전송 암호화를 쓰지 않고 서명과 인증만 합니다. 가정 · 사무실 같은 신뢰할 수 있는 내부 네트워크를 전제로 합니다.
- **인증서 검증**: 사용자가 승인한 호스트에 한해 인증서 지문을 저장하고 대조합니다. 승인하지 않은 호스트의 인증서 오류는 연결을 막습니다.
- **암호화와 수출 규정**: 앱은 표준 암호화(TLS, SFTP 의 SSH)만 사용하며, App Store Connect 의 수출 규정 문항에 그에 맞게 답합니다. 이 앱은 프랑스에서 배포하지 않습니다.

## 8. 요청하는 권한과 서드파티 라이브러리

| 권한 | 용도 |
|---|---|
| 로컬 네트워크 (`NSLocalNetworkUsageDescription`) | 사설 IP(예: 192.168.x.x)의 NAS · SMB · SFTP 서버에 접속하기 위해 씁니다. 처음 연결할 때 tvOS 가 한 번 묻습니다. |

그 밖에 위치, 연락처, 마이크, 카메라, 사진, 추적(ATT) 등 다른 권한은 요청하지 않습니다.

포함된 서드파티 라이브러리는 모두 오픈소스입니다.

- **TVVLCKit 3.7.3** (VideoLAN, LGPL v2.1 이상) — 「내장 VLC」 재생, SMB · SFTP 동영상 재생
- **MPVKit 1.1.0-n9.0.2** (mpv · FFmpeg · libplacebo 등, LGPL-2.1+ / LGPL-3.0+) — 「고화질 (mpv)」 재생
- **AMSMB2** (libsmb2 포함, LGPL v2.1 이상) — SMB 연결
- **SFTP 연결**: Citadel(MIT)과 swift-nio-ssh · swift-nio · swift-crypto(BoringSSL 포함) 등 의존 패키지

이 라이브러리들에는 데이터 수집 · 분석 · 광고 기능이 없습니다. LGPL 재링크 자료와 소스 제공(서면 제의)은 [지원 페이지의 오픈소스 절]({{ '/nasplayer-tv/support/' | relative_url }})과 [https://github.com/yjinchoi/nasplayer-relink](https://github.com/yjinchoi/nasplayer-relink) 에 있습니다. 라이선스 전문은 앱의 설정 → 정보 → 오픈소스 라이선스에서 볼 수 있습니다.

## 9. 어린이 개인정보

개발자는 13세 미만 아동을 포함해 누구의 개인정보도 수집하지 않습니다. 모든 데이터는 사용자의 Apple TV 와 사용자의 서버에만 머무릅니다.

## 10. 사용자의 권리와 삭제 방법

- **서버 프로필 · 자격 증명**: 설정 → NAS 프로필에서 프로필을 삭제하면 서버 주소, 계정 정보, 2FA 토큰, 최근 폴더 기록이 Keychain 에서 함께 지워집니다. 서버의 파일에는 영향이 없습니다.
- **이어보기 기록**: 설정 → 데이터 → 이어보기 기록 지우기.
- **이미지 캐시**: 설정 → 데이터 → 이미지 캐시 비우기(메모리에만 있으며 앱 종료 시에도 사라집니다).
- **진단 로그**: 설정 → 진단 → 진단 로그에서 화면 기록을 지울 수 있습니다.
- **앱 삭제**: 앱을 삭제하면 앱 컨테이너의 설정과 파일이 함께 삭제됩니다. tvOS 는 앱을 삭제해도 Keychain 항목을 지운다고 보장하지 않으므로, 확실히 지우려면 삭제 전에 앱에서 프로필을 먼저 지워 주세요. iCloud 로 동기화된 설정값은 같은 Apple 계정의 다른 Apple TV 에 남을 수 있습니다.

개발자가 보유한 사용자 데이터가 없으므로, 개발자를 상대로 열람 · 정정 · 삭제를 요청할 대상이 없습니다.
