# 지원

**적용 대상**: Easy NAS Photo Viewer (iOS) **버전**: 1.0

---

## 이 앱들에 대하여

이 개발자는 서로 **독립된 iOS 앱 세 개**를 만듭니다. 필요한 것만 골라 설치하면 됩니다 —
셋을 다 설치할 필요는 없고, 하나가 다른 하나를 요구하지도 않습니다.

| 앱 | 하는 일 | Synology NAS 필요 |
|---|---|---|
| **Easy Web Image Collector** (홈화면 `WebImage`) | 웹 브라우저에서 원하는 이미지를 탭해 아이폰에 내려받습니다 | **아니오** — 설치 후 설정 없이 바로 씁니다 |
| **Easy NAS Photo Viewer** (홈화면 `NASPhoto`) | 아이폰과 Synology NAS(또는 SMB 공유 폴더)의 사진·동영상을 보고, 둘 사이에서 파일을 주고받습니다 | 예 (SMB 공유 폴더로도 됩니다) |
| **Easy NAS Download Manager** (홈화면 `Downloads`) | 본인이 소유한 Synology NAS 의 Download Station 을 원격으로 관리합니다 | **예 (필수)** |

세 앱은 **자격 증명과 설정을 공유하지 않습니다.** 각각 따로 설정합니다(→ 아래 FAQ).
같은 기기에서 함께 쓰는 것은 광고 제거 구매 상태뿐입니다.

- **본인 소유의 Synology NAS** (DSM 7.x 권장) — Easy NAS Photo Viewer 는 SMB 공유 폴더도 됩니다

## 자주 묻는 질문 — 공통

### Q. 이 앱이 내 데이터를 수집하나요?

개발자는 수집하지 않습니다. 개발자가 운영하는 서버가 없고, 앱이 개발자에게 보내는 요청이 없습니다.
분석 SDK · 제3자 크래시 리포팅을 사용하지 않습니다.

다만 무료 앱이라 **Google AdMob 광고**를 보여 주며, 광고를 불러올 때 앱 안의 Google SDK 가 일부 기기
데이터를 Google 로 보냅니다. 처음 실행할 때 iOS 의 **추적 허용** 창이 한 번 뜹니다 — 허용하면 관심사에 맞는
광고가 나오고(광고 식별자 사용), 허용하지 않으면 비개인화 광고만 나옵니다. 어느 쪽이든 기능과 광고 횟수는
같습니다. 자세한 내용은 개인정보 처리방침을 봐 주세요.

### Q. 맞춤 광고(추적 허용)를 끄거나 켜고 싶습니다

**iOS 설정 › 개인정보 보호 및 보안 › 추적** 에서 이 앱의 스위치를 바꿉니다. 끄면 다음 광고부터 비개인화
광고만 요청합니다. 유럽경제지역 · 영국 등에서는 앱의 **설정 → 광고 제거 → 광고 개인정보 설정** 에서
Google 광고 동의도 바꿀 수 있습니다.

### Q. 아이폰과 아이패드 사이에 설정이 동기화되나요?

**설정값 일부는 동기화됩니다.** 외관, 검색 엔진, 정렬 방식, 기본 폴더 지정 같은 값이
Apple 의 iCloud Key-Value 저장소를 통해 같은 Apple ID 의 다른 기기로 넘어갑니다.
앱 안에 켜고 끄는 토글은 없고 조용히 동작합니다.

**자격 증명은 동기화되지 않습니다.** NAS 주소·계정·비밀번호·2단계 인증 시드는 iOS Keychain 에
**이 기기 전용**(`ThisDeviceOnly`)으로 저장되므로 다른 기기로 넘어가지 않습니다. 기기 백업에도
들어가지 않습니다. 새 기기에서는 **다시 입력**해야 합니다.

> 이전 앱(SynoBrowser)의 문서는 "iCloud Keychain 으로 자격 증명이 동기화된다"고 안내했습니다.
> 코드 확인 결과 그것은 사실이 아니었고, 이 문서에서 정정합니다.

동기화가 아예 싫으면 iOS 설정 → [사용자 이름] → iCloud 에서 해당 앱의 iCloud 사용을 끄면 됩니다.

### Q. 앱을 지우면 데이터가 남나요?

앱을 삭제하면 그 앱의 로컬 데이터(앱 폴더의 파일 · 설정)가 함께 사라집니다. 몇 가지는 남을 수 있습니다.

- iCloud 로 동기화된 설정값은 같은 Apple ID 의 다른 기기에 남아 있을 수 있습니다.
- iOS 는 앱을 삭제해도 Keychain 항목을 지운다고 보장하지 않습니다. 저장된 계정을 확실히 지우려면
  삭제하기 전에 앱 안에서 프로필을 지워 주세요. 광고 제거 구매 기록은 다른 두 앱을 위해 남습니다.
- Easy Web Image Collector 와 Easy NAS Photo Viewer 는 두 앱이 함께 쓰는 저장 공간에 파일을 둡니다. 한쪽 앱이 남아 있으면 그 파일도 남습니다.

### Q. 앱 안에서 저장된 데이터를 지우고 싶습니다

설정 화면에 저장된 데이터를 지우는 항목이 있습니다. **위치와 이름은 앱마다 다릅니다** —
「데이터」 섹션에 모여 있는 앱도 있고, 「브라우저」 섹션의 `웹 데이터 지우기` 하나로
끝나는 앱도 있습니다. 각 버튼은 확인 대화상자를 한 번 띄우고, 실행하면
**되돌릴 수 없습니다.**

### Q. 화면이 항상 밝게/어둡게 나옵니다

**설정 → 외관** 에서 라이트 · 다크 · 시스템 중에 고릅니다. 기본값은 시스템입니다.

### Q. 문제가 생겼습니다. 무엇을 보내면 되나요?

설정 화면의 **`진단 로그`** 에서 실행 중 기록을 보고 공유 시트로 내보낼 수 있습니다.
(앱에 따라 「진단」 또는 「정보」 섹션 안에 있습니다.)

로그는 기기 안에만 있고 **자동으로 전송되지 않습니다.** 사용자가 직접 보낼 때만 나갑니다.
로그에는 동작 시각과 결과, 오류 메시지, 앱이 접속한 서버 주소와 요청 경로가 담길 수 있습니다.
비밀번호와 2단계 인증 시드는 담기지 않고, 서버 세션 키는 기록 전에 마스킹됩니다.
**이 내용이 함께 전달된다는 점을 알고 보내 주세요.** 첨부 없이 문의해도 됩니다.

### Q. 앱 세 개가 같은 NAS 를 쓰는데 왜 설정을 각각 해야 하나요?

의도된 설계입니다. 세 앱은 자격 증명을 담는 Keychain 저장소를 **공유하지 않습니다** — 한 앱이
다른 앱의 자격 증명을 읽을 수 없도록 접근 그룹을 앱마다 독립시켰습니다(세 앱이 함께 읽는 것은
광고 제거 구매 기록 하나뿐입니다). 대신 NAS 주소·계정·2단계 인증·
인증서 신뢰를 앱마다 한 번씩 설정해야 합니다.

## 자주 묻는 질문 — 이 앱

### Q. 업로드와 다운로드를 어디서 고르나요?

**고르지 않습니다.** 파일이 어디에 있느냐가 어디로 갈지를 정합니다.

- NAS 폴더에서 파일을 선택하면 → 아이폰으로 **내려받습니다.**
- 아이폰 폴더에서 파일이나 폴더를 선택하면 → NAS 로 **올립니다.**

방향을 고르는 버튼이 앱에 없는 이유입니다. 업로드할 때만 「어디에 올릴지」를 묻고,
다운로드는 언제나 아이폰의 「내려받은 항목」 폴더로 들어갑니다.

### Q. NAS 폴더에서 폴더를 통째로 내려받을 수 없습니다

맞습니다. **NAS → 아이폰 방향은 파일만** 됩니다. 선택 항목에 폴더가 섞이면 다운로드 버튼이
꺼집니다. DSM 이 폴더를 하나로 묶어 내려주는 기능을 이 앱이 쓰는 API 로는 제공하지 않기 때문입니다.

반대 방향은 됩니다 — **아이폰 → NAS 는 폴더째** 올릴 수 있고, 하위 폴더 구조가 NAS 에
그대로 만들어집니다.

### Q. 아이폰 사진 앱에 있는 사진을 NAS 로 올리고 싶습니다

아이폰 폴더 화면의 **사진 보관함에서 업로드…**(또는 업로드 버튼 → **사진 보관함에서 고르기**)를 누르면
iOS 의 사진 선택기가 열립니다. 여러 장 · 동영상을 고른 뒤 올릴 NAS 폴더를 정하면 원본 형식 그대로 올라갑니다.

사진 선택기는 앱과 분리된 시스템 화면이라 **앱은 사용자가 고른 항목만** 받습니다. 그래서 사진 보관함
읽기 권한을 묻지 않습니다.

다른 방법도 됩니다 — 사진 앱에서 공유 버튼 → 이 앱을 고르면 「받은 항목」에 들어오고, 거기서 골라 올리면 됩니다.

### Q. 전송 중에 다른 앱을 써도 되나요?

**업로드(아이폰 → NAS)는 멈추지 않습니다.** 올릴 항목을 iOS 의 백그라운드 전송에 맡기므로 화면을 끄거나
다른 앱으로 가도 계속 올라갑니다. 앱이 내려간 사이 끝난 결과는 다음에 앱을 열 때 반영됩니다.

**내려받기(NAS → 아이폰)는 백그라운드 전송을 지원하지 않습니다.** 받는 동안에는 앱을 화면에 띄워 두세요.

폴더를 통째로 올리다 중간에 실패하면 **이미 올라간 파일은 NAS 에 남습니다.** 지우는 쪽이
더 위험하다고 판단했기 때문입니다. 진행률 화면의 실패 건수를 보고 다시 올리면 설정 → 업로드 →
「파일 중복 시 자동 이름 변경」 에서 정한 규칙(자동 번호 또는 덮어쓰기)이 적용됩니다.

### Q. 동영상이 재생되지 않습니다

재생 방식을 바꿔 보세요. 설정 → 동영상 → **기본 재생 방식**에 네 가지가 있습니다.

1. **내장 VLC** — 가장 폭넓은 코덱·컨테이너를 다룹니다. MKV·AVI·WMV·FLV 는 보통 여기서 열립니다.
2. **직접 재생 (AVPlayer)** — Apple 표준. MP4·MOV·H.264·HEVC 에 가장 매끄럽고 PiP·AirPlay 가 됩니다.
3. **Video Station** — NAS 가 변환해서 보내 줍니다. NAS 에 Video Station 패키지가 설치돼 있어야 합니다.
4. **다른 앱으로 열기** — VLC for iOS 등 외부 플레이어로 넘깁니다.

매번 고르고 싶다면 설정 → 동영상 → **재생 시 선택 시트 표시**를 켜세요.

**NAS 동영상 재생에는 NAS 의 HTTP 포트(DSM 기본 5000)가 열려 있어야 합니다.**
재생 엔진들은 각자의 네트워크 스택을 쓰기 때문에, 앱이 저장해 둔 자체 서명 인증서 신뢰를
공유하지 못합니다. HTTPS 만 열어 두었다면 DSM 제어판에서 HTTP 를 켜 주세요.
(Synology 의 DS file 도 같은 방식입니다.)

### Q. 자막이 안 나옵니다

동영상과 **같은 폴더**에 **같은 이름**의 `.srt` · `.smi` · `.vtt` 파일이 있어야 자동으로 붙습니다.
`movie.mkv` 에는 `movie.srt` 또는 `movie.ko.srt` 가 맞습니다.

- `.smi`(SAMI) 안에 언어별 클래스가 여러 개 있으면 **각각 별도 트랙**으로 나뉘어 재생 중 메뉴에서 바꿀 수 있습니다.
- 인코딩은 자동으로 판별합니다 — UTF-8 · CP949 · EUC-KR · Shift-JIS · Big5.
- 글자 크기 · 색 · 외곽선 · 배경은 설정 → 동영상 → **자막 기본 스타일**에서 바꿉니다. 재생 중에도 즉시 반영됩니다.

### Q. 영상이 중간부터 시작합니다

**이어보기가 자동으로 동작한 것입니다.** 보던 영상을 다시 열면 멈춘 지점부터 재생됩니다.
고를 필요도, 켤 필요도 없습니다.

처음부터 보고 싶으면 재생이 시작될 때 잠깐 뜨는 **「처음부터」** 를 누르거나, 진행 막대를
0 으로 끌면 됩니다. 끝까지 본 영상은 기록이 스스로 지워집니다.
기록 전체를 없애려면 설정 → 데이터 → **이어보기 기록 지우기**.

### Q. 「받은 항목」과 「내려받은 항목」은 뭐가 다른가요?

- **받은 항목** — 다른 앱의 공유 시트나 파일 앱을 통해 **밖에서 들어온** 파일.
- **내려받은 항목** — 이 앱이 **NAS 에서 내려받은** 파일.

둘 다 「iPhone 폴더」 안에 있습니다. 이 폴더는 Easy Web Image Collector 와 함께 쓰는 기기 안의 공유 저장
공간이라 **파일 앱의 「나의 iPhone」에는 보이지 않습니다**(그 앱이 받은 이미지는 「웹 이미지」 폴더로 보입니다).
파일 앱이나 Mac 의 Finder 로 이 앱의 폴더에 넣은 파일은 다음 실행 때 「iPhone 폴더」로 옮겨집니다.

### Q. 내장 VLC 재생은 어떤 라이선스인가요?

VideoLAN 의 **MobileVLCKit (LGPL v2.1 이상)** 을 동적 프레임워크로 포함하고 있습니다.
라이선스 전문 · 저작권 · 소스 저장소 링크는 앱 안의 **설정 → 오픈소스 라이선스**에 있습니다.
GPL 전용 플러그인은 포함하지 않았습니다. 오픈소스는 이것과 SMB 연결용 **AMSMB2(libsmb2, LGPL v2.1 이상)**
둘이고, 그 밖의 서드파티는 광고 표시용 Google Mobile Ads SDK 하나입니다.

### Q. 이 앱은 Synology 가 만든 앱인가요?

**아닙니다.** 이 앱은 Synology Inc. 가 만들거나 보증한 앱이 아닌 독립 개발 앱입니다.
`Synology` · `DiskStation` · `DSM` · `QuickConnect` · `Video Station` 은 Synology Inc. 의
상표이며, 이 문서와 App Store 설명에서는 **이 앱이 어느 기기와 동작하는지를 말하기 위해서만**
씁니다. 지원 문의는 Synology 가 아니라 아래 연락처로 주세요.

## 자주 묻는 질문 — NAS 연결

### Q. NAS 에 접속할 수 없습니다

순서대로 확인해 주세요.

1. **주소** — 같은 Wi-Fi 안이면 LAN IP(예: `192.168.1.10`), 밖에서는 DDNS 또는 QuickConnect ID.
2. **포트** — DSM 기본값은 HTTP `5000` / HTTPS `5001`. 바꿨다면 그 번호.
3. **HTTPS 와 자체 서명 인증서** — DSM 이 자체 서명 인증서를 쓰면 첫 접속에서 신뢰 확인
   대화상자가 뜹니다. 거부하면 연결되지 않습니다.
4. **방화벽** — DSM 제어판 → 보안 → 방화벽에서 해당 포트가 막혀 있지 않은지 확인.
5. **2단계 인증** — 계정에 2FA 가 켜져 있으면 OTP 를 입력하거나, 설정에 OTP 시드를 넣어
   앱이 코드를 자동 계산하게 할 수 있습니다.

### Q. "로컬 네트워크 접근" 권한을 왜 묻나요?

iOS 14 부터는 앱이 사설 IP(`192.168.x` · `10.x` 등)에 처음 닿을 때 시스템이 한 번 묻습니다.
집 안의 NAS 가 대개 그런 주소입니다. **앱은 기기를 자동으로 탐색하거나 스캔하지 않습니다** —
사용자가 설정에 직접 입력한 주소로만 연결합니다. 이 권한을 거부하면 LAN 상의 NAS 에
접속할 수 없습니다.

### Q. 자체 서명 인증서가 계속 거부됩니다

설정에서 해당 NAS 프로필의 연결을 한 번 실행하고, 그때 뜨는 신뢰 확인을 수락하세요.
앱은 사용자가 승인한 인증서의 **지문을 저장해** 다음 접속에 대조합니다. 서버에서 인증서를
새로 발급하면 지문이 달라져 다시 물어봅니다 — 그때는 프로필을 지우고 다시 만드는 것이
가장 확실합니다.

### Q. NAS 를 여러 대 쓰고 싶습니다

설정에서 NAS 프로필을 여러 개 등록하고 전환할 수 있습니다. 프로필마다 주소·계정·2단계
인증·폴더 설정이 독립적으로 유지됩니다.

### Q. 다른 기기에서 프로필이 안 보입니다

자격 증명은 기기를 벗어나지 않습니다(위 공통 FAQ 참조). 새 기기에서는 프로필을 다시
만들어야 합니다.
